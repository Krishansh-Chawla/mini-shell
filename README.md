# Mini Shell GUI

A lightweight, custom command-line shell featuring a graphical user interface (GUI) built completely from scratch in Python using only standard libraries (`os`, `shlex`, `subprocess`, and `tkinter`)[cite: 1]. 

## Features
* **Dark Theme Terminal:** Features a sleek dark-themed GUI output window (`#1e1e1e`) with custom text styling[cite: 1].
* **Built-in Commands:** Supports core shell operations including `cd`, `pwd`, `echo`, and `exit`[cite: 1].
* **Subprocess Execution:** Dynamically captures and displays both `stdout` and `stderr` for system utilities[cite: 1].

## Project Files
* **`mini.py`**: The core application containing the Tkinter GUI layout and command execution logic[cite: 1].
* **`nums.py`**: A helper script designed to test command-line argument parsing[cite: 2, 3].
* **`test.md`**: A reference guide containing helpful test commands to run inside the shell[cite: 3].

## Getting Started
1. Ensure you have Python 3 installed.
2. Download or clone this repository.
3. Run the shell application locally using your preferred method:
   python3 mini.py
